🔌 OpenDSS-G Time-Mode Co-Simulation (DSTCP Protocol)

96-Step (15-min interval = 24h) AC Power Flow Co-Simulation over Direct Server TCP (127.0.0.1:6345). Enforces 3 × Delta M88H rating (Pmpp = 210 kW, kVA = 210 kVA), battery [20%, 90%] SoC dispatch, and active power curtailment via %Pmpp for strict zero grid re-injection (P_grid ≥ 0).

TCP 127.0.0.1:6345: Checking...
1. Select Control Mode:
Mode A (Local BMS + LoadShape.dss): OpenDSS-G uses its internal 96-step LoadShape.dss profiles (minterval=15). At each step k, the controller charges the battery from surplus PV (up to 90% SoC), discharges on deficit (down to 20% SoC), and throttles %Pmpp = (P_PV_dispatched / 210.0) × 100 so P_grid ≥ 0 kW.
